# 需求记录（2026-10-13）

- 框架：GPUI Fast（https://github.com/longbridge/gpui-fast）桌面程序，学习 86 版五笔。
- 平台：只需 macOS。
- 输入方式：用户用**系统五笔输入法**打汉字上屏，程序比对汉字是否正确（参考 wongsingfo/86wubi 的做法）。
- 拆字展示：**结构化字根 + 键盘高亮**——字根序列、每个字根对应键位、末笔识别码说明，在虚拟键盘上高亮。
- 练习文本：用户可以自己添加/编辑练习文字。
- 存储：所有数据存 SQLite，包括练习文本和进度。
- 进度粒度（全部都要）：
  - 每篇文本的当前位置（下次继续）
  - 每个字的熟练度 / 错误次数（可用于错字重练、统计）
  - 每次练习的速度 / 准确率历史
- 参考 UI：wongsingfo/86wubi，但 UI 要明显改进。
